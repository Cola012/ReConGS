# ReConGS

**Cross-View Feature Coupling and Reliability-Aware Gaussian Refinement for Text-to-3D Generation**

Jiaheng Xu

This repository contains the static project website. The paper and implementation are coming soon.

## Publish with GitHub Pages

1. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder at the root of the `main` branch.
2. Open **Settings → Pages → Build and deployment**.
3. Select **Deploy from a branch**, choose **main** and **/ (root)**, and save.

The expected project URL is **https://cola012.github.io/ReConGS/** after a successful Pages deployment.

No package installation or build step is needed. To preview locally:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Content

- The author, method, figures, quantitative results, and human evaluation aggregates are taken from the current manuscript and user-confirmed results.
- Gallery examples are two real rendered views of each asset, cropped from the paper's qualitative figure. They are not interactive 3D viewers or synthesized turntable videos.
- Paper and code buttons are marked **Coming soon**. Replace them with links after the corresponding resources are public.
- The citation is for this project, using a `misc` entry. Update it with the paper's publication information when available.
- No affiliation, publication venue, paper URL, or acceptance status has been invented.
